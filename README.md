# Notification usage report (通知履歴)

Usage figures for the Search Array in-app notification history (the bell icon), from production,
as of 2026-10-23. Bilingual (EN / 日本語) — use the toggle at the top right.

An appendix covers the product's two other notification channels, browser push and notification
email, which are separate features with separate records.

**Aggregates only.** No user ids, no email addresses, no notification bodies.
